# NEXUS V1

A client-side NeoForge utility and interface framework for Minecraft 1.21.11.

## Build

Requires JDK 21. Run `./gradlew build` (Windows: `gradlew.bat build`). The distributable mod jar is written to `build/libs/`.

## Controls

Open the Nexus ClickGUI with Right Shift by default. All features are client-side informational, visual, and interface utilities; no combat automation, packet manipulation, or server-side changes are included.

## Compatibility

- Minecraft 1.21.11
- NeoForge 21.11.48
- Java 21
